Sprites in this folder are from **Kenney's Particle Pack** (https://kenney.nl/assets/particle-pack),
licensed CC0 (public domain) — no attribution required, credited here anyway.

Grayscale-on-transparent sprites, meant to be tinted via CSS `mask-image` +
`background` color (see `SkillEffectOverlay` in `BattleScreen.tsx`), not used
as-is.

- `slash.png` — DAMAGE_DEALER hit archetype (was `slash_04.png`, thin arc — read as an actual blade swipe, unlike the wider crescents `slash_01-03.png`)
- `magic-bolt.png` — SUPPORT hit archetype (was `magic_03.png`)
- `spark.png` — crit accent (was `spark_03.png`)
- `flare.png` — unused placeholder, kept for future archetypes (was `flare_01.png`)
